#Login System (Android)

A simple **Login System** built in **Android Studio** using **Java**.  
It includes username & password fields, error validation messages, a **Remember Me** checkbox, and a **written logo** ("Digital Space").  

---

## 🚀 Features
- ✏️ Username & Password input fields  
- ⚠️ Error validation for empty fields  
- 🔑 Hardcoded login credentials for demo (`admin / 1234`)  
- ✅ "Remember Me" functionality using **SharedPreferences**  
- 🎨 Clean white background with centered layout  
- 🖋️ Logo text at the top ("Digital Space")  
- 📲 Redirects to a simple **Dashboard screen** on successful login
